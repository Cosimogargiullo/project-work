# Screenshot

La presente cartella contiene le evidenze visuali dei test funzionali del progetto CareHub.

Gli screenshot documentano il comportamento effettivo dell'applicazione durante l'esecuzione dei casi di test e costituiscono prova oggettiva dei risultati riportati nella matrice test funzionali.

## Contenuto della cartella

La struttura e organizzata per aree funzionali:

* login
* registrazione-paziente
* profilo-utente
* disponibilita
* appuntamenti
* referti
* gestione-utenti
* dashboard-economica

Sono inoltre presenti i file di supporto:

* README.md: guida operativa della sezione screenshot
